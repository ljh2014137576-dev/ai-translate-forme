参数说明

API Key
DeepSeek 密钥：访问 platform.deepseek.com → API Keys 创建。仅保存在本地浏览器。
Base URL
接口地址，默认 https://api.deepseek.com 即可；只有用自建代理/中转时才需要改。
模型
DeepSeek 模型名，默认 deepseek-chat。点「获取模型」自动拉取你账号可用的模型列表，支持下拉选择或手动输入。
目标语言
网页文字要翻译成的语言，例如：简体中文、English、日本語。输入框支持搜索与下拉选择。
每批字符数
每个 API 请求携带的源文本字符数。越大请求次数越少但单次更慢；普通页面默认即可。
并发数
同时发出的请求数量。越大越快但更容易触发限流，默认 3 已平衡速度与稳定。
默认模式
打开弹窗时默认高亮的显示模式：原文 / 译文 / 双语，与页面脚本配合切换展示。
保留缓存
翻译结果按页面保存到本地，重复打开同一页面可直接复用，节省 token。
自动应用
打开已缓存的网站时自动应用翻译缓存，无需手动点击翻译。
站点规则
按站点单独设置「自动应用」与「保留缓存」，可覆盖全局设置；修改后即时保存。
Token 用量
统计调用模型消耗的 prompt / completion / total 与请求次数，可随时重置。
