DeepSeek 密钥，访问 platform.deepseek.com → API Keys 创建，仅保存在本地。

接口地址，默认 https://api.deepseek.com 即可；只有用自建代理/中转时才需要修改。

DeepSeek 模型名，默认 deepseek-chat；点击「获取模型」自动拉取账号可用模型，支持下拉选择或手动输入。

网页文字要翻译成的目标语言，支持输入或下拉选择。

你的主要阅读语言；网页主要语言与之相同时将自动跳过翻译，不请求 AI、不留缓存。

打开弹窗时默认高亮的显示模式：原文 / 译文 / 双语。

每个 API 请求携带的源文本字符数，范围 100~20000；越大请求次数越少但单次更慢。

同时发出的请求数量，范围 1~10；越大越快但更容易触发限流。

全局开关

翻译结果按页面保存到本地，重复打开同一页面可直接复用，节省 token。

打开已缓存的网站时自动应用翻译缓存，无需手动点击翻译。

过期缓存会被自动清理；设置为长期保留的页面不受影响。
